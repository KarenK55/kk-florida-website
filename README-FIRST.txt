KK FLORIDA PROFESSIONAL WEBSITE

UPLOAD
1. Extract this ZIP into its own new folder.
2. Open that folder. You should see index.html plus css, js, data, tools, and images folders.
3. Upload the complete structure to GitHub.
4. Commit changes.
5. Cloudflare redeploys automatically.

BEST UPLOAD METHOD
GitHub Desktop preserves folders more reliably than selecting individual files in the browser.
You may also drag the actual folders css, js, data, tools, and images into GitHub's upload page.

ADDING PHOTOS
- Add a watermarked web-sized JPEG to the correct images category folder.
- Open tools/gallery-builder.html on your computer.
- Load the current data/gallery.json file.
- Fill in the new photo information.
- Download the new gallery.json.
- Replace data/gallery.json in GitHub.

WATERMARK
Use a web copy about 1800–2200 pixels wide.
Add “KK Florida Photography” before uploading.
Keep the full-resolution unwatermarked original for Picfair.
