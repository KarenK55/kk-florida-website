UPLOAD TO GITHUB
1. Extract this ZIP.
2. Open your kk-florida-website repository.
3. Click Add file > Upload files.
4. Drag every extracted file and folder into GitHub.
5. Click Commit changes.

NETLIFY
Import the GitHub repository into Netlify. Leave Build command blank and use . as the Publish directory.

EDITOR
Enable Netlify Identity, set registration to Invite only, enable Git Gateway, invite your email, then open https://YOUR-SITE.netlify.app/admin/.

Replace the temporary sample pictures with your own photographs and designs in the editor.
