5Publish through GitHub Desktop


    

  1. After downloading the ZIP, open it in Windows File Explorer and choose Extract All to a temporary folder.
    2. 

  2. Copy the data and images folders from the extracted ZIP into your local kk-florida-website repository folder. Choose Merge folders and Replace the existing data/gallery.json when asked. Do not delete existing folders.
    3. 

  3. Open GitHub Desktop. Review your changes, enter a commit message such as Add new KK Florida photographs, then click Commit to main and Push origin.
    4. 

  4. Your GitHub workflow regenerates the category pages, main sitemap and image sitemap. Cloudflare Pages then deploys the published changes.
    5.
