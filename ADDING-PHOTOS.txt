HOW TO ADD YOUR OWN PHOTOS

1. Prepare a web copy:
   - Resize to about 1800–2200 pixels wide.
   - Use JPEG quality around 80–88%.
   - Add your watermark before uploading.
   - Keep the full-resolution unwatermarked original for Picfair.

2. Upload the photo to the correct GitHub folder:
   images/birds/
   images/butterflies/
   images/dragonflies/
   images/flowers/
   images/everglades/
   images/sunsets/
   images/reptiles/
   images/insects/
   images/tshirts/

3. Open data/gallery.json in GitHub and click the pencil icon.

4. Copy an existing item and change it. Example:

{
  "title": "Roseate Spoonbill",
  "category": "Birds",
  "description": "Photographed in the Florida Everglades.",
  "image": "images/birds/roseate-spoonbill.jpg",
  "link": "https://YOUR-EXACT-PICFAIR-PHOTO-LINK",
  "store": "Picfair"
}

5. Add a comma between items, commit the change, and Cloudflare will redeploy automatically.

WATERMARKING
Add the watermark before uploading the website copy.
Recommended:
- Text: KK Florida Photography
- White or light gray
- 35–45% opacity
- Lower-right corner
- Keep it readable but not distracting

Use unwatermarked originals only on Picfair.
