HOW TO ADD YOUR OWN PHOTOS

This version uses NO folders. All website files and photos may remain in the main GitHub folder.

1. Prepare a web copy:
- Resize to about 1800–2200 pixels wide.
- Save as JPEG.
- Add your watermark before uploading.
- Keep the unwatermarked original for Picfair.

2. Rename the photo clearly:
roseate-spoonbill.jpg
everglades-sunset.jpg
green-dragonfly.jpg

3. Upload the photo to the main level of the GitHub repository.

4. Open gallery.json and click the pencil icon.

5. Add an item like this:

{
  "title": "Roseate Spoonbill",
  "category": "Birds",
  "description": "Photographed in the Florida Everglades.",
  "image": "roseate-spoonbill.jpg",
  "link": "https://YOUR-EXACT-PICFAIR-LINK",
  "store": "Picfair"
}

6. Put a comma between entries.
7. Commit changes.
8. Cloudflare redeploys automatically.

WATERMARK
Add it before uploading.
Recommended:
- KK Florida Photography
- White or light gray
- 35–45% opacity
- Lower-right corner
